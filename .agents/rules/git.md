# Git Execution Rules

## Git 명령어 자동 실행 규정
1. **즉시 실행 (Auto-Execute)**:
   - 모든 `git` 관련 명령어(`git status`, `git add`, `git commit`, `git push`, `git pull`, `git checkout`, `git branch`, `git log` 등)는 사용자에게 추가 승인을 묻지 않고 즉시 submit/실행합니다.
   - 프로젝트 내부 파일 억세스 및 커밋/푸시 작업 시 질문이나 확인 대기 없이 바로 진행합니다.
2. **동작 범위**:
   - 현재 리포지토리(`d:\_YDE\_Develope\_PRIVATE_PROJECT\Qubeat`) 내부의 모든 Git 작업에 적용됩니다.
